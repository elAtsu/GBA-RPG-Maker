Installation

Follow these steps to get started:

  1. Follow Butano's installation guide. This program is required to compile your project.
  2. Install GBA RPG Maker's latest version, run the portable version or open the web version.
  3. Done!

Assets

To make your own assets (graphics or audio) check out Butano's Importing assets page.

Action Reference

This are all the actions avaliable currently:

Action Description Parameters
Show Message Displays a textbox and prints a message on screen. Message
Change Level Changes from one sreen to another.
  • Level
  • Player's X position
  • Player's Y position
Stop Music Stops all sounds that are currently playing.
Play Music Plays a song on a loop. Music file
Show/Hide Object Shows or hides the specified object.
  • Object's ID
  • Show / Hide
Show/Hide Object Shows or hides the player. Show / Hide
Mini Menu Displays a menu with two options.
  • Option 1's text
  • Option 2's text
Start Battle Begins a battle with the specified enemy. Enemy
Restore Health Restores set amount of health. Amount
Restore Mana Restores set amount of mana. Amount

Frequently Asked Questions (FAQ)

Is the program free?

Yes, it is also open source under the zlib license.

Can I update the generated code?

Yes, you can edit the generated code to suit your needs and make your game better! Just remember that you'll need to learn some C++ first.

How can I report a bug?

If you find an error, please open an issue on the GitHub repository.
