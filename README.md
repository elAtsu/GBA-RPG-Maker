# GBA RPG Maker
A simple tool to make small RPGs for the Game Boy Advance without the need to code.

## Instalation
Download and install [GValiente's Butano](), this tool is necessary to compile your project.

After the installation, download the [latest release of GBA RPG Maker]() for your operating system.

## Getting Started
Before you begin using the program, I recommend you check out the [documentation]() or the [video guide]().
